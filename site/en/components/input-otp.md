# InputOtp

<p class="page-desc">The filled type matches Arco VerificationCode; the default outlined type keeps the Element Plus form. See the <a href="https://element-plus.org/en-US/component/input-otp.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Filled Code

Use type="filled" for Arco-style cells and size to adjust their dimensions.

::: demo input-otp/basic
:::

## Other Types

Arco has no outlined or underlined equivalent; both keep the Element Plus form.

::: demo input-otp/types
:::

## Differences from Arco

- Cells use fixed gaps instead of Arco's evenly distributed layout.
- Focus behavior follows Element Plus; outlined and underlined have no Arco equivalent.
