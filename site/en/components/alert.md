# Alert

<p class="page-desc">Maps to Arco Alert by color: primary matches info, and info matches normal. See the <a href="https://element-plus.org/en-US/component/alert.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Alert Types

Primary, success, warning and error match Arco statuses; info uses neutral gray.

::: demo alert/basic
:::

## Description & Closing

Description adds supporting text; the close button keeps normal interaction.

::: demo alert/description
:::

## Dark Effect

Arco has no dark effect; it retains the Element Plus solid form.

::: demo alert/dark
:::

## Differences from Arco

- Status icons use Element Plus icons; the dark effect has no Arco equivalent.
