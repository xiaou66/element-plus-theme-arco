# InputTag

<p class="page-desc">Matches Arco InputTag with light bordered tags inside a filled input. See the <a href="https://element-plus.org/en-US/component/input-tag.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Basics & Disabled

Type a value and press Enter to add a tag; disabled prevents editing.

::: demo input-tag/basic
:::

## Tag Styles

Arco has no equivalent tag-type or tag-effect; these use the theme's Tag styles.

::: demo input-tag/tag-props
:::

## Differences from Arco

- Close icons come from Element Plus; Arco has no tag-type or tag-effect configuration.
