# Input

<p class="page-desc">Matches Arco Input with a gray fill and a primary border on focus. See the <a href="https://element-plus.org/en-US/component/input.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

The size prop maps to Arco's three sizes; disabled keeps the disabled state.

- Character-count spacing and textarea resize handles follow Element Plus.
