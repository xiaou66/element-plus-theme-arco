# SelectV2

<p class="page-desc">Uses Arco Select styling with Element Plus virtual scrolling for large option lists. See the <a href="https://element-plus.org/en-US/component/select-v2.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Large Option Lists

Generate 1,000 options; virtual scrolling limits how many are rendered at once.

::: demo select-v2/basic client-only
:::

## Differences from Arco

- Items are 34px by default; set item-height to 36 to match Arco.
- Keyboard highlighting starts at the selected option, following Element Plus.
