# Mention

<p class="page-desc">Matches Arco Mention with the filled input and Select-style suggestions. See the <a href="https://element-plus.org/en-US/component/mention.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Mention Suggestions

Type @ to open suggestions, then select with the keyboard or mouse.

::: demo mention/basic client-only
:::

## Differences from Arco

- The panel follows the caret and sizes to its content; Arco places a full-width panel below the input.
