# Tag

<p class="page-desc">Maps to Arco Tag by color: info is neutral and other types use Arco status colors. See the <a href="https://element-plus.org/en-US/component/tag.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

Light creates tinted tags, plain maps to bordered and dark uses solid colors.
