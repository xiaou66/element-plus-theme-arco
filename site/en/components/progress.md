# Progress

<p class="page-desc">Matches Arco Progress with line, circle and status variants. See the <a href="https://element-plus.org/en-US/component/progress.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Line Progress

A stroke width of 4 matches Arco; exception maps to Arco danger.

::: demo progress/basic
:::

## Circle Progress

Props control circle dimensions and stroke width; status colors match Arco.

::: demo progress/circle
:::

## Differences from Arco

- The default stroke is Element Plus's 6px; set stroke-width to 4 for Arco.
- Status variants show only an icon; Arco also shows the percentage.
