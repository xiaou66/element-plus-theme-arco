# Switch

<p class="page-desc">Matches Arco Switch with borderless default and small sizes. See the <a href="https://element-plus.org/en-US/component/switch.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Basics & Disabled

Default and small match Arco's sizes; lighter colors distinguish disabled states.

::: demo switch/basic
:::

## Labels & Extended Size

Inline prompts match Arco labels; large and external labels have no Arco equivalent.

::: demo switch/text
:::

## Differences from Arco

- The large size extends Arco using Element Plus size increments and has no direct Arco equivalent.
- External labels and loading icons follow Element Plus.
