# ColorPicker

<p class="page-desc">Uses Arco ColorPicker trigger colors while keeping the Element Plus panel layout. See the <a href="https://element-plus.org/en-US/component/color-picker.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Trigger & Sizes

Click a swatch to open the panel; size provides three trigger sizes.

::: demo color-picker/basic client-only
:::

## Alpha & Inline Panel

Use ElColorPickerPanel to display alpha and preset colors directly on the page.

::: demo color-picker/panel client-only
:::

## Differences from Arco

- The hue slider is vertical; color input and Clear / Confirm actions retain the Element Plus layout.
- Disabled swatches keep Element Plus opacity to distinguish the state.
