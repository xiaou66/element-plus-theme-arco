# Tabs

<p class="page-desc">The default line and card types map to Arco's corresponding tab variants. See the <a href="https://element-plus.org/en-US/component/tabs.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

The default matches Arco line; click a tab to change its content.

Border-card has no Arco equivalent and keeps the Element Plus header and content structure.

## Closing & Positions

Closing and side positions retain Element Plus behavior; removing the active tab updates the selection.

::: demo tabs/editable
:::

## Differences from Arco

- Border-card and left/right positions retain the Element Plus layout.
- Close controls use Element Plus icons.
