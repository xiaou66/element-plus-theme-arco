# Tree

<p class="page-desc">Matches Arco Tree with title hover backgrounds and primary selected text. See the <a href="https://element-plus.org/en-US/component/tree.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Basic Tree

Highlight-current marks the selected node; an indent of 22 matches Arco.

::: demo tree/basic
:::

## Checkbox Tree

Show-checkbox matches Arco checkable; disabled nodes cannot be checked.

::: demo tree/checkbox
:::

## Differences from Arco

- Indentation defaults to 18px; set indent to 22 to match Arco.
- Disabled nodes without checkboxes keep their Element Plus appearance; expand icons differ from Arco.
