# Breadcrumb

<p class="page-desc">Matches Arco Breadcrumb with subtle hover backgrounds on linked items. See the <a href="https://element-plus.org/en-US/component/breadcrumb.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Basic Hierarchy

The final item represents the current page; linked items navigate normally.

::: demo breadcrumb/basic
:::

## Icon Separator

Separator-icon replaces text separators with an Element Plus icon.

::: demo breadcrumb/icon
:::

## Differences from Arco

- The default separator is a text slash rather than Arco's slash icon; separator-icon can replace it.
