# Calendar

<p class="page-desc">Matches Arco Calendar's month view with a primary circle for the selected date. See the <a href="https://element-plus.org/en-US/component/calendar.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Month View

Click a date to select it and use the header controls to change months.

::: demo calendar/basic
:::

## Differences from Arco

- The month determines whether five or six rows appear; Arco always shows six.
- The header keeps Element Plus navigation buttons and default English locale text.
