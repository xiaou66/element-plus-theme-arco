# Pagination

<p class="page-desc">Matches Arco Pagination by default with a tinted primary background for the current page. See the <a href="https://element-plus.org/en-US/component/pagination.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Basics & Sizes

Three sizes follow the theme scale; clicking a page updates the current value.

::: demo pagination/basic client-only
:::

## Background & Disabled

Background is an Element Plus solid extension; disabled pagination remains non-interactive.

::: demo pagination/background client-only
:::

## Full Layout

The full layout keeps Element Plus totals, page-size selection and jump controls; narrow containers scroll horizontally.

::: demo pagination/layout client-only
:::

## Differences from Arco

- The page-size selector keeps Element Plus's fixed default width; Arco sizes it to content.
- Background and full layouts retain Element Plus configuration.
