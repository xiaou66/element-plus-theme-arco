# Backtop

<p class="page-desc">Matches Arco BackTop with a primary round control targeting only the example's scroll area. See the <a href="https://element-plus.org/en-US/component/backtop.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Scroll Area Backtop

Scroll the area to reveal the button; clicking it returns only this area to the top.

::: demo backtop/basic
:::

## Differences from Arco

- Right and bottom default to Element Plus's 40px rather than Arco's 24px; configure them explicitly when needed.
