# Anchor

<p class="page-desc">The default maps to Arco line-less; underline maps to Arco's default track. See the <a href="https://element-plus.org/en-US/component/anchor.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Differences from Arco

- Width follows the container rather than Arco's fixed 150px.
- Clicking a link retains Element Plus URL-hash behavior.
