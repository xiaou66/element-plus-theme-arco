# InputNumber

<p class="page-desc">Maps to Arco InputNumber: side controls match button mode and right-hand controls match embed mode. See the <a href="https://element-plus.org/en-US/component/input-number.html" target="_blank" rel="noreferrer">Element Plus docs</a> for props.</p>

## Side Controls

Default controls match Arco button mode; align="left" aligns the value.

::: demo input-number/basic
:::

## Right Controls

Right controls match Arco's default embed mode and appear on hover or focus.

::: demo input-number/right
:::

## Without Controls

Setting controls to false matches Arco hide-button.

::: demo input-number/no-controls
:::

## Differences from Arco

- Element Plus centers values by default; set align="left" for Arco alignment.
- Control icons and keyboard focus behavior differ from Arco.
