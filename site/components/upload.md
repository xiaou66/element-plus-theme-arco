# 上传 Upload

<p class="page-desc">对应 Arco Upload：支持拖拽区域与图片卡片。示例仅选择文件，不发起上传。 属性用法见 <a href="https://element-plus.org/zh-CN/component/upload.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 拖拽选择

`drag` 对应 Arco `draggable`，`:auto-upload="false"` 让示例只选择文件。

::: demo upload/basic
:::

## 图片卡片

`list-type="picture-card"` 展示本地图片及可继续选择的卡片。

::: demo upload/picture-card
:::

## 与 Arco 的差异

- 拖拽区图标由使用者提供，使用 Element Plus 图标时形状与 Arco 默认加号不同。
