# 消息弹框 MessageBox

<p class="page-desc">对应 Arco Modal.confirm 场景，<code>center: true</code> 对应 simple 的居中标题与按钮。 属性用法见 <a href="https://element-plus.org/zh-CN/component/message-box.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 提示、确认与输入

点击按钮分别打开 alert、confirm、prompt，取消操作会显示结果。

::: demo message-box/basic
:::

## 居中确认

`center: true` 对齐 Arco simple 场景，取消与确认保留正常行为。

::: demo message-box/center
:::

## 与 Arco 的差异

- 默认显示关闭按钮，Arco simple 默认没有；默认形态保留 Element Plus 对齐方式。
