# 分割线 Divider

<p class="page-desc">对应 Arco 的 Divider：<code>direction</code> 控制方向，<code>content-position</code> 对应 Arco 的文字位置。 属性用法见 <a href="https://element-plus.org/zh-CN/component/divider.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 水平与文字位置

`content-position` 的 `left`、`center`、`right` 对应 Arco 的同名文字位置。

::: demo divider/basic
:::

## 垂直分割

在一行内容中使用 `direction="vertical"` 分隔相邻文字。

::: demo divider/vertical
:::

## 与 Arco 的差异

无明显差异。
