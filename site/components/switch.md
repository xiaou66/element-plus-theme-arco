# 开关 Switch

<p class="page-desc">对应 Arco Switch：默认和 small 对应 Arco 两档尺寸，无可见边框。 属性用法见 <a href="https://element-plus.org/zh-CN/component/switch.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 基础与禁用

默认和 small 对应 Arco 两档尺寸，禁用态以浅色区分。

::: demo switch/basic
:::

## 文字与扩展尺寸

`inline-prompt` 对应 Arco 内嵌文字；large 和外部文字是 Arco 没有的形态。

::: demo switch/text
:::

## 与 Arco 的差异

- `large` 是按 Element Plus 尺寸级差延伸的形态，Arco 没有对应项。
- 外部文字布局与加载图标保留 Element Plus。
