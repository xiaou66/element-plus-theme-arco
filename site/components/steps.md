## 简洁步骤

:::

## 纵向步骤

纵向形态保留 Element Plus 布局并使用主题状态色。

::: demo steps/vertical client-only
:::

## 与 Arco 的差异

- finish 默认显示数字，Arco 显示对勾；连线填充时机和布局宽度算法保留 Element Plus。
- 默认靠左、simple 和 vertical 形态按主题配色，布局保留 Element Plus。
