# 气泡卡片 Popover

<p class="page-desc">对应 Arco Popover，使用浅色面板、标题与正文层级。 属性用法见 <a href="https://element-plus.org/zh-CN/component/popover.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 点击卡片

点击按钮打开带标题的卡片，`width` 控制面板宽度。

::: demo popover/basic client-only
:::

## 悬停卡片

`trigger="hover"` 悬停显示，自适应宽度保留正常交互。

::: demo popover/hover client-only
:::

## 与 Arco 的差异

- 默认宽度保留 Element Plus 的 150px，可按内容传 `width="auto"`。
