# 菜单 Menu

<p class="page-desc">对应 Arco 的浅色 Menu，支持纵向、横向和折叠菜单。 属性用法见 <a href="https://element-plus.org/zh-CN/component/menu.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 纵向菜单

默认纵向菜单对应 Arco vertical，点击子菜单可展开选项。

::: demo menu/basic client-only
:::

## 横向菜单

`mode="horizontal"` 对应 Arco 横向导航，选中项显示底部主色条。

::: demo menu/horizontal client-only
:::

## 折叠菜单

切换 `collapse` 保留 Element Plus 的折叠布局，配色使用主题变量。

::: demo menu/collapse client-only
:::

## 与 Arco 的差异

- 菜单项保留 Element Plus 的键盘聚焦行为。
