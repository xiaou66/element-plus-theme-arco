# 对话框 Dialog

<p class="page-desc">对应 Arco Modal，默认标题靠左，center 对应居中标题与按钮。 属性用法见 <a href="https://element-plus.org/zh-CN/component/dialog.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 基础对话框

点击按钮打开对话框，取消、确认和关闭按钮均可关闭。

::: demo dialog/basic
:::

## 居中对话框

`center` 配合 `align-center` 居中标题、按钮与弹窗位置。

::: demo dialog/center
:::

## 与 Arco 的差异

- 默认保留 Element Plus 的顶部距离；`align-center` 可实现 Arco 默认的垂直居中。
