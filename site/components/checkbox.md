# 多选框 Checkbox

<p class="page-desc">对应 Arco Checkbox：选中时标签保持主要文字色，悬停时显示圆形背景。 属性用法见 <a href="https://element-plus.org/zh-CN/component/checkbox.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 基础与状态

选中、半选和禁用状态对应 Arco Checkbox。

## 按钮组

Arco 没有复选按钮组，这里按 Arco 单选按钮组风格延伸。

::: demo checkbox/buttons
:::

## 尺寸与边框

Arco 没有独立复选框尺寸和边框形态，这里保留 Element Plus 的配置语义。

::: demo checkbox/sizes
:::

## 与 Arco 的差异

- 按钮组、独立复选框的尺寸和 `border` 没有 Arco 对应项，按 Arco 风格延伸或保留 Element Plus 形态。
