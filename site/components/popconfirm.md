# 气泡确认框 Popconfirm

<p class="page-desc">对应 Arco Popconfirm，使用小尺寸操作按钮与状态图标。 属性用法见 <a href="https://element-plus.org/zh-CN/component/popconfirm.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 点击确认

点击 Delete 打开确认框，确认和取消都会更新状态。

## 与 Arco 的差异

- 默认问号图标与 Arco 信息图标不同。
- 取消按钮默认保留 Element Plus 的文字形态；可用 `cancel-button-type="default"` 得到灰底按钮。
