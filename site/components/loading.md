# 加载 Loading

<p class="page-desc">区域加载对应 Arco Spin，遮罩与提示使用主题颜色。 属性用法见 <a href="https://element-plus.org/zh-CN/component/loading.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 区域加载

使用 Switch 控制 `v-loading`，加载遮罩覆盖已有内容。

::: demo loading/basic
:::

## 全屏加载

点击按钮显示全屏遮罩，2 秒后自动关闭；这是 Arco 没有的扩展形态。

::: demo loading/fullscreen
:::

## 与 Arco 的差异

- 加载图标形状不同；全屏加载保留 Element Plus 的较大图标，Arco 没有对应项。
