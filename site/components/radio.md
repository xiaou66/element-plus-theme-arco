## 按钮组与尺寸

::: demo radio/buttons
:::

## 独立尺寸与边框

Arco 没有独立尺寸和边框形态，这里保留 Element Plus 的配置语义。

::: demo radio/border
:::

## 与 Arco 的差异

- 独立单选框的尺寸与 `border` 没有 Arco 对应项，保留 Element Plus 形态。
- 按钮组保留键盘焦点框，组末尾外边距与 Arco 不同。
