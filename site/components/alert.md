# 警告提示 Alert

<p class="page-desc">按颜色对应 Arco Alert：primary 对应 info，info 对应 normal。 属性用法见 <a href="https://element-plus.org/zh-CN/component/alert.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 提示类型

primary、success、warning、error 对应 Arco 状态；info 使用中性灰。

::: demo alert/basic
:::

## 标题、描述与关闭

`description` 展示补充说明，关闭按钮保留正常交互。

::: demo alert/description
:::

## 实心提示

`effect="dark"` 在 Arco 中没有对应项，保留 Element Plus 的实心形态。

::: demo alert/dark
:::

## 与 Arco 的差异

- 状态图标保留 Element Plus 图标集；dark 效果没有 Arco 对应项。
