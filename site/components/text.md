# 文本 Text

<p class="page-desc">对应 Arco 的 Typography.Text：默认使用主要文字色，状态色由 <code>type</code> 指定。 属性用法见 <a href="https://element-plus.org/zh-CN/component/text.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 文字类型

`type` 切换主色与状态色，默认对应 Arco 主要文字。

::: demo text/basic
:::

## 尺寸

`size` 保留 Element Plus 的三档字号。

::: demo text/sizes
:::

## 文字省略

指定宽度后，`truncated` 会将超出的文字省略。

::: demo text/truncated
:::

## 与 Arco 的差异

- `info` 没有 Arco 对应项，保留中性灰；`size` 沿用 Element Plus 三档尺寸。
