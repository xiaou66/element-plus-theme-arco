# 头像 Avatar

<p class="page-desc">对应 Arco Avatar，支持文字、图标、尺寸与头像组。 属性用法见 <a href="https://element-plus.org/zh-CN/component/avatar.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 尺寸与形状

`size` 和 `shape` 对应 Arco 的尺寸与形状。

::: demo avatar/basic
:::

## 头像组

`el-avatar-group` 将头像叠放，并显示分隔描边。

::: demo avatar/group
:::

## 与 Arco 的差异

- 长文字不会像 Arco 一样自动缩小，建议使用简短缩写。
