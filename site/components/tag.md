# 标签 Tag

<p class="page-desc">按颜色对应 Arco Tag：<code>info</code> 是默认灰色标签，其他类型对应 Arco 状态色。 属性用法见 <a href="https://element-plus.org/zh-CN/component/tag.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 颜色与形态

light 对应浅色标签，plain 对应 bordered，dark 对应实心色。

::: demo tag/effects
:::

## 尺寸与关闭

三档尺寸对应 Arco small、medium、large，点击关闭按钮移除标签。

::: demo tag/sizes
:::

## 可选中标签

`el-check-tag` 对应 Arco 的 `checkable` 标签。

::: demo tag/checkable
:::

## 与 Arco 的差异

- 关闭按钮使用 Element Plus 图标，笔画与 Arco 不同。
