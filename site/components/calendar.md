# 日历 Calendar

<p class="page-desc">对应 Arco Calendar 的月视图，选中日期以主色圆形标识。 属性用法见 <a href="https://element-plus.org/zh-CN/component/calendar.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 月视图

点击日期修改选中值，通过表头按钮切换月份。

:::

## 与 Arco 的差异

- 根据月份显示五行或六行日期，Arco 固定显示六行。
- 表头保留 Element Plus 按钮组，日期文字由默认英文语言包提供。
