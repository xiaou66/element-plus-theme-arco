# 折叠面板 Collapse

<p class="page-desc">对应 Arco Collapse：默认箭头在右，<code>expand-icon-position="left"</code> 对应 Arco 默认。 属性用法见 <a href="https://element-plus.org/zh-CN/component/collapse.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 基础折叠

点击标题展开或收起，默认箭头在右侧。

::: demo collapse/basic
:::

## 左侧箭头与手风琴

左侧箭头对应 Arco 默认；`accordion` 每次只展开一项。

::: demo collapse/left
:::

## 与 Arco 的差异

- 箭头使用 Element Plus 线形图标，键盘聚焦标题时保留主色提示。
