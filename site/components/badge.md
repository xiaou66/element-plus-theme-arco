# 徽标 Badge

<p class="page-desc">对应 Arco Badge：<code>value</code> 对应 count，<code>is-dot</code> 对应 dot。 属性用法见 <a href="https://element-plus.org/zh-CN/component/badge.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 数字与封顶

`max` 限制显示的最大数字，`value` 也支持英文文字。

::: demo badge/basic
:::

## 圆点与状态色

`is-dot` 搭配 `type` 展示不同状态的圆点。

::: demo badge/dot
:::

## 与 Arco 的差异

无明显差异。
