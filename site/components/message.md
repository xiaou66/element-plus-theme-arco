<p class="page-desc">对应 Arco Message：primary 对应 info，各类型都使用浅色面板与状态图标。 属性用法见 <a href="https://element-plus.org/zh-CN/component/message.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 简洁提示

`plain` 是 Arco 没有的形态，与默认描边提示保持区别。

::: demo message/plain
:::

## 与 Arco 的差异

- 图标集不同；info 保留 Element Plus 灰色图标。
- `plain` 没有 Arco 对应项，保留无可见描边的阴影形态。
