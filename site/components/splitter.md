# 分隔面板 Splitter

<p class="page-desc">对应 Arco 的 Split 使用场景：保留 Element Plus 的面板与分隔条结构，颜色使用 Arco 风格。 属性用法见 <a href="https://element-plus.org/zh-CN/component/splitter.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 可折叠面板

拖动分隔线调整面板宽度，`collapsible` 开启折叠按钮。

::: demo splitter/basic
:::

## 纵向布局

`layout="vertical"` 将面板上下排列。

::: demo splitter/vertical
:::

## 与 Arco 的差异

- 分隔条与折叠按钮保留 Element Plus 结构，与 Arco 带拖拽点的分隔条不同。
