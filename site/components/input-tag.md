# 标签输入框 InputTag

<p class="page-desc">对应 Arco InputTag：灰底输入框内的默认标签为浅色描边。 属性用法见 <a href="https://element-plus.org/zh-CN/component/input-tag.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 基础与禁用

输入英文内容后按 Enter 添加标签；`disabled` 禁止编辑。

::: demo input-tag/basic
:::

## 标签样式

`tag-type` 和 `tag-effect` 在 Arco 中没有对应项，按主题的 Tag 风格延伸。

::: demo input-tag/tag-props
:::

## 与 Arco 的差异

- 关闭图标使用 Element Plus 图标；`tag-type` 和 `tag-effect` 是 Arco 没有的配置。
