# 标签页 Tabs

<p class="page-desc">默认 line 和 card 分别对应 Arco 的同名标签形态。 属性用法见 <a href="https://element-plus.org/zh-CN/component/tabs.html" target="_blank" rel="noreferrer">Element Plus 文档</a>。</p>

## 线形标签

默认线形对应 Arco line，点击标题切换内容。

::: demo tabs/basic
:::

## 卡片标签

`type="card"` 对应 Arco card，内容区域带边框。

::: demo tabs/card
:::

## 带边框卡片

Arco 没有对应的 border-card，保留 Element Plus 的头部与内容结构。

::: demo tabs/border-card
:::

## 关闭与位置

关闭标签和左右布局保留 Element Plus 的配置语义，移除当前项时同步更新选中项。

::: demo tabs/editable
:::

## 与 Arco 的差异

- `border-card` 和左右标签位置保留 Element Plus 布局。
- 关闭图标使用 Element Plus 图标集。
